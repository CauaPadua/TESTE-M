# Para minha pessoa favorita

Site estático feito com HTML, CSS e JavaScript puro.

## Como testar
- Abra `index.html` no navegador; ou publique todos os arquivos deste diretório na raiz do repositório do GitHub.
- Não renomeie nem mova a pasta `fotos`.
- Senha da cartinha: `princesa`.

## Publicar no GitHub Pages
No repositório, abra Settings > Pages, selecione Deploy from a branch, branch `main` e pasta `/ (root)`. Os arquivos `index.html`, `style.css`, `script.js` e a pasta `fotos` precisam ficar na raiz do repositório (não dentro de outra pasta).
